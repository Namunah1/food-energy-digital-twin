# Final Audit

Performed mechanically against the actual restructured repository (file
counts, import graphs, and link checks were run with real tools this
session, not estimated). Every finding below is either fixed already
(noted) or explicitly flagged as remaining.

## Structural issues found and fixed during this consolidation

1. **Broken path resolution caused by the restructuring itself**:
   `backend/app/model_bridge.py` hardcoded a path assuming
   `backend/model_src/...`; the new `/backend /model` separation broke
   this. Fixed, verified via the full pytest suite (10/10 API tests, 46
   model tests) before declaring the restructuring complete.
2. **Data-directory conflict**: `model/src/model.py` independently
   resolves data at `model/../data`. Resolved via `model/data` as a
   symlink to the top-level `data/` -- single source of truth, no
   duplicated ~10MB of CSVs.
3. **Empty, unused `backend/app/routers/` directory** -- nothing
   imported from it. Removed.
4. **A literal directory named `{fao,owid,usda,nd_gain,iea}`** in
   `data/raw/` -- an unexpanded shell brace-expansion typo from the
   original repository (confirmed empty before removal). Ironically, my
   own first attempt at creating this repository's folder structure hit
   the identical bug (this environment's shell does not expand braces);
   both instances found and fixed.
5. **A runtime SQLite database and Python bytecode caches** were
   regenerated during this session's own testing and initially leaked
   into the clean repo. Removed; `.gitignore` added to prevent
   recurrence.
6. **A near-duplicate file**: `dev_tools_regenerate_all_FASTTEST.py`
   (249 lines, 12 lines different from `regenerate_all.py`) was sitting
   inside `model/src/` where nothing imported it. Moved to `scripts/`
   as `regenerate_all_SMOKETEST.py` with its relationship to the main
   script documented, rather than silently deleted (it is a real,
   working, occasionally-useful tool) or left in a confusing location.
7. **Three more literal-brace directories, missed on the first pass**:
   `data/{raw,processed}`, `publication/{reports,figures,outlines}`,
   `tests/{model,api}` — the same class of bug as item 4, this time from
   this consolidation's own initial `mkdir -p .../{a,b,c}` setup commands
   (this environment's shell does not expand braces; a lesson learned
   twice in the same session and worth stating plainly rather than
   quietly fixing without mention). All three confirmed empty before
   removal.
8. **`.pytest_cache/` regenerated by this session's own test runs**,
   leaked into the tree before `.gitignore` existed to prevent it.
   Removed; the `.gitignore` written earlier in this pass already covers
   it for future runs.

## Checks performed, zero issues found

- **Broken internal markdown links**: 0 (checked with real
  `[text](path)` syntax parsing across all 21+ documentation files --
  first pass produced 161 false positives from inline code-formatted
  filenames in prose, which are not links; re-run against only genuine
  link syntax found none broken).
- **Dead/orphaned Python modules**: 0 genuinely dead. Six modules showed
  zero importers in the static-import scan
  (`climate_drivers.py`, `resource_drivers.py`, `regenerate_all.py`,
  `run.py`, `calibrate_rc_price_amp.py`, `data_pipeline.py`) -- each
  checked individually: the first two are intentionally-optional driver
  modules attached externally by design (not auto-imported, per the
  `model.climate_driver = None` opt-in slot pattern used throughout
  Phase C); the remaining four are legitimate CLI entrypoints, run
  directly rather than imported.
- **`node_modules`/`.next` build-artifact leakage into the clean repo**:
  none found (`frontend/` is 320K, source-only).

## Remaining, not fixed this pass (flagged, not silently ignored)

- **No hand-written per-endpoint API reference** exists for all ~30
  backend routes -- `USER_GUIDE.md` points to FastAPI's automatic
  Swagger UI (`/docs` once the server is running) and the Pydantic
  schemas as the authoritative source instead. Writing a full manual
  reference for every endpoint was judged lower value than the
  documents actually produced, given FastAPI already generates an
  accurate one from the same source of truth (the route decorators and
  schemas) -- a hand-written duplicate risks drifting out of sync with
  the real code, which is a worse outcome than no hand-written doc at
  all.
- **No class/sequence/module diagrams beyond the one causal-loop diagram**
  produced in the Phase 2.5b causal decomposition work. The 13-figure
  and 8-diagram lists requested for a full publication package were not
  produced at the requested breadth -- see the final consolidation
  report's "What was not completed" section for the explicit list and
  reasoning.
- **CONTRIBUTING.md and CODE_OF_CONDUCT.md** were not generated this
  pass -- standard boilerplate that provides real value only once actual
  contribution workflows and institutional contact points exist; a
  generic template would be lower-value filler.
- **License is a placeholder recommendation (MIT)**, not a confirmed
  choice -- flagged explicitly in `LICENSE` itself; needs confirmation
  from actual authors/institution before public release.
- **`CITATION.cff` has placeholder author/DOI/date fields** -- cannot be
  filled in honestly without real author information this session does
  not have.
